Get Message Details
Retrieve full details of a sent message including content, cost, and per-recipient delivery status.

Path Parameters
Parameter	Type	Required	Description
id	string	Required	Message ID returned from send or send-bulk endpoint


Send Bulk SMS
Send the same message to multiple recipients (up to 1,000) in a single API call. Duplicate phone numbers are automatically removed. senderId is required (same rules as single send).

Request Parameters
Parameter	Type	Required	Description
recipients	string[]	Required	Array of phone numbers (max 1,000). Duplicates are removed automatically
message	string	Required	Message content (max 480 characters / 3 segments)
senderId	string	Required	Required. Platform test sender ID (fixed "Hello from Agoo" message) or an approved custom Sender ID name.


Send SMS
Send a single SMS to one recipient. You must include senderId — the approved Sender ID name from your dashboard (not your API key). With a live key, your balance is charged; with a test key, sending is simulated and cost is 0.

Request Parameters
Parameter	Type	Required	Description
to	string	Required	Phone number in E.164 format (+233XXXXXXXXX) or local format (0XXXXXXXXX)
message	string	Required	Message content (max 480 characters / 3 segments)
senderId	string	Required	Required. Either your platform test sender ID (SMS_GATEWAY_USER_SENDER_ID — message must be "Hello from Agoo") or an approved custom Sender ID name from your dashboard (any message).
